# 简历筛选 Skill（resume-screening）

> 把"凭感觉筛简历"变成"按规则执行"的一个 Codex Skill。给 HR 用，尤其适合实习/校招的简历初筛。

## 解决什么问题

HR 筛简历最常见的问题不是不认真，而是**判断标准一直在变**：今天觉得这个人不错，明天老板一句话又觉得不合适，再来一份简历又换了套标准。标准不统一的时候，用不用 AI 结果都是乱的。

这个 Skill 的做法是：**先定标准，再看人**。

1. 拿到 JD 后，先由 HR 确认一份岗位画像问卷，明确这个岗位的硬性门槛、加分项和面试考察重点
2. 再按这套标准批量处理简历，逐项核验门槛、按五个维度打分
3. 最后输出可排序、可追溯、可视化的结果

## 核心设计

**门槛只能建立在"结构性内容"上。**

简历里的信息分两种：

- **结构性内容**（教育背景、实习/项目经历、起止时间、证书）：不写等于没内容，判断可靠，**可以设门槛**
- **可选内容**（技能栏、自我评价、期望地点、到岗时间）：写不写取决于个人习惯，"没写"说明不了任何问题，**不能设门槛**

这条原则带来两个直接后果：

- **技能一律不作门槛**。简历里写了不代表会（越会包装的人越爱写"精通"），没写也不代表不会。技能只在打分时按证据强弱加分，并列入面试验证清单。
- **到岗时间、可实习时长、期望城市不作门槛**。这些是招聘平台的字段，简历里本来就不该有，不扣分也不淘汰。

门槛设错的代价是**漏人**，而且是**不可见的漏**——你永远不会知道被淘汰的那批人里有没有好的。降成加分项之后，人还留在表里，只是排在后面，你还看得见、能回头捞。

## 安装

### 方式一：借助 Codex 安装（推荐）

对 Codex 说：

> 帮我从 GitHub 安装 skill：`<你的用户名>/resume-screening`，路径是 `resume-screening`

Codex 会用内置的 skill-installer 拉取。装好后**下一轮对话生效**。

### 方式二：手动安装

1. 下载本仓库（右上角 Code → Download ZIP），解压
2. 把解压出来的 `resume-screening` 文件夹整个复制到：
   - Windows：`C:\Users\<你的用户名>\.codex\skills\`
   - macOS / Linux：`~/.codex/skills/`
3. 重启 Codex

装好后目录应该是这样：

```
~/.codex/skills/resume-screening/
├── SKILL.md
├── references/
├── scripts/
└── assets/
```

注意别套成 `skills/resume-screening/resume-screening/`，多一层就读不到了。

## 怎么用

对 Codex 说 `$resume-screening`（或者直接说"用简历筛选 skill 帮我筛这批简历"），然后：

1. **给 JD**：把岗位 JD 发给它
2. **答问卷**：它会弹出一份岗位画像问卷，你点选确认（不确定的可以跳过，跳过的项不会进门槛）
3. **给简历**：把一个文件夹的 PDF 简历路径给它
4. **拿结果**：Excel 汇总表（按分数排序）、单人卡片（PNG）、深度报告（Markdown）

## 输出

| 文件 | 用途 |
|---|---|
| `<岗位名>-画像卡.md` | 这个岗位的筛选标准，同岗位后续批次可复用、可校准 |
| `<岗位名>-筛选结果-YYYYMMDD.csv` | 主输出，Excel 直接打开，按总分排序 |
| `cards/<姓名>.png` | 单人卡片，一览式可视化 |
| `<岗位名>-<姓名>-深度报告.md` | 单人深度分析，含得分依据、面试验证问题 |

## 评分模型

总分 100，五个维度：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 岗位硬技能匹配 | 25 | JD 明确要求的专业技能、工具、证书、专业背景 |
| 相关经历匹配 | 25 | 实习/项目经历与岗位职能的对口度、平台与角色含金量 |
| 成果与业绩证据 | 20 | 是否量化、个人贡献是否可辨识 |
| 成长性与学习力 | 15 | 经历是否递进、有无持续学习证据 |
| 投入度与稳定性 | 15 | 经历是否连续、长期坚持的证据、求职动机是否匹配 |

软性素质（责任心、进取心等）**不占分**，只用行为代理指标打标签（强证据/间接证据/未体现）+ 生成面试验证问题。因为简历里的"责任心强"是自述，不是证据。

评级：≥85 高度匹配 ｜ 70-84 基本匹配 ｜ 60-69 勉强匹配 ｜ <60 不匹配。

## 环境依赖

这个 Skill 里的脚本是 **PowerShell**（Windows），依赖两个外部工具：

| 用途 | 工具 |
|---|---|
| PDF 转文本 | `pdftotext`（随 MiKTeX 或 Poppler 安装） |
| 卡片渲染 | `xelatex`（含 `ctex` 宏包）+ `pdftoppm` |

两者只要有其一装到 PATH 里，脚本会自动找到；找不到时也可以在命令里显式指定路径。

**没有装 LaTeX 也能用**——只是单人图片卡片那一步生成不了，Excel 汇总表和深度报告不受影响。

> 目前只能在 Windows + PowerShell 下运行。macOS / Linux 需要把三个 `.ps1` 脚本改写成 shell 或 Python 版本，欢迎 PR。

## 已知的坑

- `.ps1` 脚本必须存成 **UTF-8 带 BOM**，否则 Windows PowerShell 5.1 会把中文读成乱码
- 输出的 CSV 必须带 BOM，否则 Excel 打开是乱码
- 卡片出图用 LaTeX 渲染，**不要用 AI 生图工具**——中文会画错、数字对不上
- LaTeX 里的 `●`、`○` 等符号需要用 `\xeCJKDeclareCharClass` 交给中文字体，否则会丢失字形

## 边界与声明

- 这是**初筛辅助工具**，输出的是建议，不是录用决定。最终判断以面试为准。
- 所有结论都要求引用简历原文；抓不到证据的写"简历未体现"，不作推断。
- 性别、年龄、婚育状况、籍贯、民族、照片等与岗位无关的信息**不参与评分**。
