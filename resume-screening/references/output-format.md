# 输出格式规范

Step 6 使用。按这个优先级实现和交付。

## 一、Excel 汇总表（主输出）

格式：**CSV，UTF-8 带 BOM**（Excel 直接双击打开，中文不乱码）。

文件名：`outputs/<岗位名>-筛选结果-YYYYMMDD.csv`

列定义（**列顺序固定**，不要随意改动）：

| # | 列名 | 说明 |
|---|---|---|
| 1 | 排名 | 按总分降序；淘汰和待定不参与排名 |
| 2 | 姓名 | |
| 3 | 学校 | |
| 4 | 学历 | |
| 5 | 专业 | |
| 6 | 年级 / 毕业时间 | |
| 7 | 门槛结果 | 通过 / 待定 / 淘汰 |
| 8 | 门槛依据 | 触发的是哪一条（如"违反 L1：学历不符合"） |
| 9 | 总分 | 0-100。待定候选人同样有分，标注为"条件性得分"；淘汰的留空 |
| 10 | 评级 | 高度匹配 / 基本匹配 / 勉强匹配 / 不匹配 |
| 11 | 硬技能 | 维度 1 得分 |
| 12 | 相关经历 | 维度 2 得分 |
| 13 | 成果证据 | 维度 3 得分 |
| 14 | 成长性 | 维度 4 得分 |
| 15 | 投入稳定性 | 维度 5 得分 |
| 16 | 优势 1 | 附原文依据 |
| 17 | 优势 2 | |
| 18 | 优势 3 | |
| 19 | 风险 1 | 附原文依据 |
| 20 | 风险 2 | |
| 21 | 建议 | 约面 / 待定 / 淘汰 |
| 22 | 一句话理由 | 给业务方看的那一行 |
| 23 | 待确认问题 | 需要 HR 去问候选人的 |
| 24 | 简历文件名 | 便于回溯 |

**排序规则**：先"通过"（按总分降序），再"待定"（同样按总分降序），最后"淘汰"（不打分）。三组之间视觉上分开。

待定的人**必须带分数和待确认问题**，不能只给一个"待定"就结束——那样 HR 拿到的信息量为零。正确形态是"76 分（条件性），待确认：学历信息缺失"。

**表格末尾附加**：

```
本表由 AI 辅助生成，结论基于简历书面信息，仅供参考。
最终录用判断以面试为准。统计：共 N 份，通过 X，待定 Y，淘汰 Z。
```

## 二、单人图片卡片（第二步实现）

渲染链路：**LaTeX（ctex）→ xelatex → PDF → pdftoppm → PNG**

不要用 AI 生图工具——中文会画错、数字对不上。

### 怎么用

1. 按下面结构写一份候选人 JSON，存到 `outputs/cards/<姓名>.json`
2. 运行渲染脚本：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\render_card.ps1 `
  -DataFile outputs\cards\张三.json -OutDir outputs
```

产出 `outputs/cards/<姓名>.png`（A4，150 DPI，约 1241×1754），中间产物在 `outputs/cards/_src/`。

**为什么用 JSON 而不是命令行参数**：中文长句、标点、逗号走命令行很容易被拆分或转义出错（`powershell -File` 不会把逗号分隔的参数当数组）。JSON 文件没有这个问题。

### 输入 JSON 结构

```json
{
  "岗位": "某公司 HR 招聘实习生",
  "批次": "2026-10-01",
  "姓名": "张三",
  "副标题": "西南财经大学 · 财政学 · 大四",
  "总分": 79,
  "评级": "基本匹配",
  "门槛结果": "通过（符合 L1：本科及以上在读）",
  "建议": "约面",
  "优势": ["...", "...", "..."],
  "风险": ["...", "..."],
  "维度": [
    { "名称": "硬技能", "得分": 17, "满分": 25 }
  ],
  "软性观察": ["进取心 ●●●", "抗压 ●●●"],
  "待验证项": ["Excel 熟练度", "PPT 汇报经验"]
}
```

**卡片上的文字要短**。这里是给人一眼扫的，不是完整报告——完整分析放深度报告里。

评级决定主色：高度匹配=绿，基本匹配=蓝，勉强匹配=橙，不匹配=红。条形图按得分比例自动配色。

版式：


## 三、单份深度报告（第三步实现）

Markdown 格式，文件名：`outputs/<岗位名>-<姓名>-深度报告.md`

结构：

1. **基本信息**：姓名、学校、专业、年级、求职意向
2. **总体结论**：总分、评级、一句话判断
3. **维度得分**：5 个维度逐项列出得分 + 依据（引用简历原文）
4. **核心优势 3 个**：每条必须附简历原文
5. **潜在风险 / 疑点 3 个**：每条附原文，并说明疑点在哪
6. **面试必问 5 问**：针对简历疑点和岗位要求生成，**其中至少 1 题用于验证技能水平**（如"简历里提到处理过数据，具体用了哪些函数？"），不要"你的优缺点是什么"这类空泛问题
7. **建议考察方向**
8. **合规声明**

## 四、文件组织

```
outputs/
├── <岗位名>-画像卡.md              # Step 1 产出，可复用
├── <岗位名>-筛选结果-YYYYMMDD.csv   # 主输出
├── <岗位名>-<姓名>-深度报告.md      # 按需生成
└── cards/
    └── <姓名>.png                  # 单人卡片
work/
└── extracted/
    └── <简历文件名>.txt            # PDF 转换的中间产物
```
